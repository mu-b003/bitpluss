Bash

Bash is an abbreviation of "Bourne Again SHell", and it is a powerful Scripting Language and Command Line Interpreter used primarily in Unix and Linux-based operating systems for system management, task automation, and direct interaction with the kernel.

As soon as you open the Terminal, you are probably already using Bash. To verify that, you can type the following command:

echo $SHELL

If the result is /bin/bash or /usr/bin/bash then Bash is currently running.

If your terminal uses another type (like Zsh or Fish), you can simply type:

bash

The prompt will immediately switch to work in the Bash environment. And to exit it and return to the previous shell, type exit.

    
    #!/bin/bash
    echo "Hello, World!"
    
  
#!/bin/bash:

Called "Shebang", it tells the system to use the Bash command interpreter to execute this file

echo: is a programming command used to print or display texts and data on the screen (output)

"Hello, World!": is the text string to be printed, placed between quotation marks to preserve its format

This simple script when run displays the famous greeting phrase to the user in the command interface

The script usually requires giving its file "execution" permission via the chmod +x command to work correctly

Variables

Without spaces around = , use $ to display the value

    
     #!/bin/bash
 
     name="Mubarak"
     age=22
 
     echo "My name is $name"
     echo "I am $age years old"
    
  
#!/bin/bash:

Is the declaration line (Shebang) that specifies for the programming materials in the operating system that this file should be executed using the Bash interpreter

Lines name="Mubarak" and age=22 store text and numeric values inside variables to call them later, noting no spaces around the = sign

When writing $name or $age inside text, the system understands you want to replace the variable name with the actual value stored inside it (like Mubarak)

echo: used to print the resulting texts on screen, where in this script it combines fixed texts with variable values

When running this script, the user will see two clear sentences: "My name is Mubarak" and "I am 22 years old"

User input 
    
     #!/bin/bash
 
     echo "Enter your name:"
     read name
 
     echo "Welcome $name!"
    
  
#!/bin/bash:

Specifies the path of the command interpreter (Bash) that will read and execute the programming instructions in the file

First echo: prints explanatory text on the screen asking the user to enter their name (Enter your name)

read name: is a vital command that temporarily stops script execution to wait for input from the user via keyboard, then stores what the user types in a variable called name

The echo command is used again to print a welcome message, where the value entered by the user is programmatically called using the $ symbol

This code represents the simplest form of "Input-Process-Output" in script programming

Conditions (if)

Conditions (if)

-gt greater than

-lt less than

-eq equals

    
     #!/bin/bash
 
     echo "Enter a number:"
     read num
 
     if [ $num -gt 10 ]; then
     echo "Number is greater than 10"
     else
     echo "Number is 10 or less"
     fi

The script starts by requesting a number from the user via echo and stores it in the variable num using the read command

if: the conditional statement starts with if [ $num -gt 10 ]; where the abbreviation -gt means "Greater Than", and it tests the entered value

then: if the value in $num is actually greater than 10, the programming command that follows the word then directly is executed

else: if the condition is false (meaning the number is 10 or less), execution automatically moves to execute the commands under the else section

fi: the if statement always ends with the word fi (which is the word if written in reverse), to tell the system that the comparison logic has ended here

Loops

for loop

    
     #!/bin/bash
 
     for i in 1 2 3 4 5
     do
     echo "Number: $i"
     done

for: the loop starts with for i in 1 2 3 4 5 where a temporary variable named i is created that takes a new value from the existing list (1 to 5) in each cycle

do: the word do means "do", indicating the beginning of the commands that will be repeated as long as the specified number list has not ended

The command "echo "Number: $i" prints the word followed by the current value of variable i; so you will see numbers printed one after another in each line

done: the word done is used to inform the Bash interpreter that the set of commands to be repeated has ended, so the program returns to the beginning to pick the next number

This method saves writing the print command manually five times, saving time and reducing programming errors when dealing with large data

while loop

    
     #!/bin/bash
 
     count=1
 
     while [ $count -le 5 ]
     do
     echo "Count: $count"
     ((count++))
     done

The code starts with count=1 to set the starting point of the counter from number one.

The statement while [ $count -le 5 ] means "continue as long as the counter is less than or equal to (Less than or Equal) number 5".

do: this word specifies the beginning of the programming block that will be repeatedly executed as long as the condition remains met.

((count++)): this line is extremely important, it increments the counter value by 1 in each cycle; without it the script will enter an "infinite loop" because the condition will always be true.

done: ends the loop and returns the program to the condition line to determine whether to repeat again or exit the loop.

Handling files

Create and write:

    
      #!/bin/bash
 
      echo "Hello Bash" > file.txt
    
  
echo "Hello Bash":

The engine here prepares the text "Hello Bash" for printing, but it will not appear on the screen this time

This symbol tells the system: "Do not print the text on screen, but send it to another place", in this case a text file

file.txt: if the file does not exist, the script will automatically create it, but if it already exists it will erase its old content and write the new text in its place

This procedure is called "Standard Output Redirection", and it is a fundamental means of saving command results or work logs (Logs) for later reference

If you use > it will replace the content, while if you use >> it will add the new text to the end of the file without erasing the old one

Read:

    
      #!/bin/bash
 
      cat file.txt

cat: is an abbreviation of (Concatenate), and although its name suggests merging files, its most common use is displaying the contents of text files

file.txt: represents the name of the file the script wants to access. The file must exist in the same folder where the script is executed to work successfully

The command opens the file and reads the data stored inside it (like the text "Hello Bash" we wrote earlier) then pushes it directly to the terminal screen

As soon as the script runs, you will see the file's contents as regular text in front of you, making it a quick tool for checking data without needing to open a text editor

You can use cat with several files at once (e.g. cat file1.txt file2.txt) to display them all behind each other as one sequence

Read line by line:

    
      #!/bin/bash
 
      while read line
      do
      echo "Line: $line"
      done < file.txt

while read line loop: this loop reads the file one line per cycle, and stores the content of the current line inside a variable called line

Start of execution do: starts executing commands on the line that was just captured from the file

Data processing: the command echo "Line: $line" displays the text in the line preceded by the word "Line:", which helps you distinguish each line separately

Input redirection < file.txt: the symbol < tells the while loop that the data source is not the keyboard, but the content of the file file.txt

This method is better than using cat inside a loop, because it consumes less memory and handles large files efficiently without loading the entire file into memory at once

Handling users and files 
    
    #!/bin/bash
 
    echo "Checking if file exists..."
 
    if [ -f file.txt ]; then
    echo "File exists"
    else
    echo "File not found"
    fi

The script starts by printing explanatory text "Checking if file exists..." to inform the user of the operation currently taking place.

[ -f file.txt ]: the -f operator (abbreviation for File) is a logical test that checks two things: that the file exists, and that it is a regular file (not a directory).

If the script finds the file file.txt in the specified path, it will execute the first command and print "File exists".

else: if the file is missing or has been deleted, the script automatically moves to print the warning message "File not found".

This pattern is widely used in "automation", where you cannot read or modify a file before confirming its actual existence to prevent the script from crashing.

This script works as a smart automation tool aiming to create dated backups of files to ensure data is not lost and to facilitate tracking changes over time. The process starts by defining the source variable src containing the file to be copied, followed by the most creative part which is forming the backup file name using the system command $(date +%Y%m%d), which automatically combines the current date (year, month, and day) inside the file name to make it unique for each day. Full Backup Script

This script presents a professional solution for archiving and compressing data, moving from simply copying files to reducing their size and collecting them in a single time-protected file. The code starts by specifying the data source path SOURCE and the final destination for copying DEST inside the file system, with using the DATE variable to ensure getting an accurate time stamp for each archiving operation. The real power lies in the tar -czf command; where the letter c creates the archive, z compresses it using the gzip algorithm to reduce storage space, while f specifies the name of the resulting file. This way, an entire folder of data is transformed into a single compressed file in .tar.gz format carrying today's date, which facilitates long-term transfer and storage while maintaining the original folder structure.

Log Cleanup Script

This script is designed to perform a storage space management and maintenance task by automatically cleaning old system logs (Logs) to prevent the hard disk from filling up. The code primarily relies on the programming power of the find command to search inside the directory specified in the LOG_DIR variable for regular files only using the -type f option. The essential part here is the -mtime +7 parameter which filters files whose last modification was more than seven days ago, ensuring only recent logs are retained and deleting anything older than a week. As soon as these old files are found, the script executes the rm -f command on them directly via the -exec option to permanently delete them without asking the user for confirmation, then concludes the operation by printing "Done!" to indicate the successful completion of the cleanup and space freeing operation.

Multi-Service Health Checker

This script works as a tool for Service Monitoring and Self-healing automatically, where it ensures vital system services remain running without constant human intervention. The code starts by defining a services array containing a list of target services (like web server and databases), then uses an iteration loop to check each service individually via the systemctl is-active --quiet command. The programming secret here lies in the special variable $? which saves the "Exit Status" of the previous command; if the value does not equal zero (-ne 0) this means the service is disabled or stopped. As soon as a service failure is detected, the script prints a warning message then executes the automatic restart command sudo systemctl restart to restart it immediately, while it only prints an "OK" message if the service is working properly, making this script ideal to schedule as periodic tasks (Cron Jobs) to ensure server stability.
