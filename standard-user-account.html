Standard user account

In this task we will create a standard user account and test the privileges it possesses.

Click the Windows icon type 'Computer Management' and then press Enter.

This will open for you click on 'System Tools' then 'Users and Groups'

Right-click on 'Users' to open a menu then select 'New Users'

Enter a username and a password you can remember.

Right-click on 'TestUser' to open a small menu then go to the 'Member Of' tab. You will see something like 'User' indicating a standard user account. If you wish to grant administrator privileges you can do so using the 'Add' option—a process we previously explained in the task regarding the creation of an administrator account.

Log out

Try logging in with the new account you create and entering the password.

Click the Windows icon and type 'Run' a small menu will open.

Type cmd

Type `net user TestUser` in the Command Prompt (cmd). It will show you details about the account.

Attempting to run a command with administrator privileges ("Run as administrator")

As a result a standard user cannot run the Command Prompt (cmd) with administrator privileges they can only do so by entering the administrator password.

Deleting accounts

Click the Windows icon and go to Settings.

Then the accounts.

After accessing the accounts select 'Family & other users'

Then tap on the user you wish to delete and select 'Delete' A message stating 'Remove' account and data' will appear once you select this option the account along with all associated folders, files, and data will be deleted.
