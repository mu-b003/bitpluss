TCP/IP model

A simplified, 4-layer working model, actually used on the Internet, which is the basis on which networks operate today.

Transport Layer: Responsible for reliable (TCP) or fast (UDP) data transmission.

Internet Layer: Responsible for routing and IP addresses (corresponding to the Network layer in OSI).

Application Layer: Combines the Session, Presentation and Application layers in OSI.

The OSI model is a theoretical, educational model consisting of 7 layers and is used to understand how networks work in detail, while the TCP/IP model is a practical model consisting of 4 layers and is the one actually used to run the Internet.

IP Addressing

IPv4 and IPv6

IPv4 (Internet Protocol Version 4): It consists of 32 bits and is written in the format of 4 numbers separated by periods, such as 17.17.224.47 Its number of addresses is limited and has become almost exhausted.

IPv6 (Internet Protocol Version 6): It consists of 128 bits, is designed to solve the problem of running out of IPv4 addresses, and provides a huge number of addresses.

Public vs Private IP addresses

Public IP: A unique address used for internet communication, accessible from anywhere in the world.

Private IP: An address used only within the local network (such as 192.168.xx) and not displayed directly on the internet.

Static vs Dynamic IP addresses

Static IP: A fixed address that does not change, usually used for servers.

Dynamic IP: An address that changes automatically, and is often distributed via the DHCP protocol.

Network Subnetting

The process of dividing a large network into smaller subnets to improve performance, streamline address management, and increase security.

CIDR (Classless Inter-Domain Routing)

A writing method used to specify the size of a subnet, such as 192.168.1.0/24, where the number after the slash indicates the number of bits allocated to the subnet portion.
