الانظمة الافتراضية

ما هي الآلة الافتراضية (VM)؟

الـ Virtual Machine هي محاكاة كاملة لجهاز كمبيوتر داخل جهازك الحقيقي. يعني تشغّل نظام تشغيل كامل (مثل Linux أو Windows) داخل نافذة على جهازك دون أن يؤثر على نظامك الأصلي.

جهازك الحقيقي يسمى Host (المضيف) الجهاز الافتراضي داخله يسمى Guest (الضيف) البرنامج الذي يدير الـ VM يسمى Hypervisor كل VM معزولة تماماً — ما يحصل فيها لا يضر الجهاز الأصلي

طبقات الـ Virtualization

نوعا الـ Hypervisor

Type 1 — Bare Metal

🖥️ Type 2 — Hosted

تثبيت VirtualBox وإنشاء أول VM

تحميل VirtualBox

اذهب إلى virtualbox.org وحمّل النسخة المناسبة لجهازك

تحميل ISO للنظام الضيف

مثلاً Ubuntu Linux من ubuntu.com/download — ملف .iso

إنشاء VM جديدة

في VirtualBox: New ← اختر اسماً ← نوع النظام ← خصّص الـ RAM (2GB كحد أدنى)

إنشاء قرص صلب افتراضي

اختر VDI ← Dynamically allocated ← حجم 20GB على الأقل

ربط ملف ISO وتشغيل التثبيت

Settings ← Storage ← اختر ملف ISO ← Start ← اتبع خطوات تثبيت Ubuntu

عزل الشبكة (Network Isolation)

إذا جعلت الـ VM في وضع Bridged Adapter ، تصبح جزءاً من شبكتك المحلية — أي برمجية خبيثة داخلها يمكنها مهاجمة أجهزة أخرى على نفس الشبكة!
