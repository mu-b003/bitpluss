File system structure

In Linux everything is considered a file within a tree structure that begins at the root directory / and all files and directories are located beneath that root.

The command `cd /` is used to navigate to the root directory which is the highest level in the file system.

The `pwd` command is used to find out your current location.

Then use the `ls` command to display the contents of the root folder.

Use the `cd /home` command to navigate to the home directory then `pwd` to verify you are inside it followed by `ls` to list its contents this reveals a directory named kali.

We used the `cd kali` command to enter Kali then the `pwd` command to determine our current location.

Once again we used `cd /` to navigate to the root directory and entered the command `cd root` but a "Permission denied" message appeared because the "kali" user does not have permission to access the root directory.

That is why we used `sudo -i` to switch to the root user as you can see it worked and we verified that we were in the root directory using the `pwd` command.

`cd /etc` to navigate to the directory containing system and program configuration files.

The `ls` command is used to display all contents within this directory.

The `cd /bin` command is used to navigate to the `bin` directory which contains the essential Linux commands required by both the system and the user.

Then use `ls` to list the commands.

The command `cd /usr` is used to navigate to the `usr` directory which contains programs, applications, libraries, and documentation.

ls to display its contents

We entered the `bin` directory again using the command `cd /bin` and displayed the first 10 items of its contents 'ls | head'.

The command `cd /var` is used to navigate to the `/var` directory the files within this directory change constantly while the system is running.

ls to display the contents of this directory

The `cd log` command is used to navigate to the `log` directory where all system logs are stored these logs record everything that happens within the system.

`ls` to display its contents and the results revealed various log files.

The command `cd /tmp` is used to navigate to the `/tmp` directory which is designated for storing temporary files created by programs while they are running.

pwd to find the current location

The command `cd /dev` is used to navigate to the `dev` directory. This directory contains files representing system devices—such as the hard drive and the terminal—reflecting the fact that Linux treats devices as files.

The `cd /boot` command is used to navigate to the `boot` directory which contains files required by the system to start up.

Then run `ls` to display the contents of this directory.
