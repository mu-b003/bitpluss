Wireshark

Wireshark is the world's most widely used network protocol analyzer.

It allows security professionals to capture, inspect, and analyze network traffic in real time.

Wireshark is commonly used for network troubleshooting, incident response, digital forensics, and penetration testing.

Why Use Wireshark?

Wireshark helps analysts understand what is happening on a network by examining individual packets.

It can reveal communication between systems, protocols in use, authentication attempts, and potential security issues.

How Wireshark Works

1- Capture network traffic.

2- Display captured packets.

3- Analyze protocols and data.

4- Identify network behavior.

5- Investigate security events.

Packet Analysis

Main Components

Packet List Pane

Displays all captured packets.

Each packet contains:

• Source Address

• Destination Address

• Protocol

• Packet Length

• Additional Information

Packet Details Pane

Displays protocol information for the selected packet.

Example:

Ethernet
IP
TCP
HTTP
Packet Bytes Pane

Displays the raw packet data in hexadecimal and ASCII format.

Capturing Traffic

Select a network interface and start capturing packets.

Common interfaces:

• Ethernet

• Wi-Fi

• VPN Interfaces

• Loopback Interface

icmp

Display Filters

Display filters allow analysts to focus on specific traffic.

Filter by IP Address
ip.addr == 192.168.1.10
Filter by Source IP
ip.src == 192.168.1.10
Filter by Destination IP
ip.dst == 192.168.1.20
Filter by TCP Port
tcp.port == 22
Filter by HTTP Requests
http.request
Filter by DNS Queries
dns

Following Streams

Wireshark can reconstruct entire conversations.

Example:

Right Click Packet
→ Follow
→ TCP Stream

This allows viewing complete communications between systems.

TCP Three-Way Handshake

Wireshark is commonly used to analyze TCP connections.

Client ---- SYN ----> Server

Client <-- SYN/ACK -- Server

Client ---- ACK ----> Server

DNS Analysis

Wireshark can identify:

• DNS Queries

• DNS Responses

• Suspicious Domains

• DNS Tunneling Activity

HTTP Analysis

Inspect HTTP requests and responses.

Example:

GET /login HTTP/1.1

Host: example.com

Useful for understanding web application behavior.

Credential Discovery

In insecure protocols, credentials may appear in plaintext.

Examples:

FTP

Telnet

HTTP

Always analyze captured traffic responsibly and within authorized environments.

Common Shortcuts

Important Note

Wireshark is a packet analyzer, not an exploitation tool.

Its strength lies in visibility and understanding network communications.

Many security issues can be identified simply by analyzing traffic and recognizing abnormal behavior.
