JavaScript

JavaScript is a high-level, dynamic, interpreted programming language, considered the cornerstone for developing interactive web pages. It works primarily inside web browsers to add interactivity, such as animations, instant content updates, and form validation. It managed to dominate website development and expanded to include web server development Node.js

Running JavaScript

Easiest way: Open Chrome browser, press F12, go to Console and type:

    
     console.log("Hello JavaScript");

console: is a programming "object" that provides access to browser control and programming tools

.log(): is a "method" used to print or display data and information in the control panel (Console)

"Hello JavaScript": is the text to be displayed, placed between quotation marks because it is treated as a "string"

Parentheses (): used to wrap the data we pass to the function for it to process and print

Semicolon ;: used to end the programming statement, a sign that tells the engine the command is complete here

Variables

Used to store data

    
     let name = "Ali";
     let age = 20;
 
     console.log(name);
     console.log(age);

Defining variables (let): used the reserved word let to create "containers" in memory to store data

Storing texts: variable name holds the value "Ali", which is a string because it is between quotation marks

Storing numbers: variable age holds the value 20 as a numeric type (Number), does not need quotation marks

Calling values: when writing console.log(name), the program searches for the value stored inside the name and displays it

Result in Console: you will see the word Ali in one line, and the number 20 in the next line

Declaration types:

    
      let x = 10;     // Regular variable (changes)
      const y = 5;    // Constant (does not change)
      var z = 3;      // Old (avoid it)

let (default choice): used when you know the variable's value will change later (like a counter in a loop). Distinguished by respecting "Block Scope", meaning it lives only inside the {} it was written in.

const (safer): used for values that will never change. Modern programming recommends always using const unless you are sure you will need to change the value, as this prevents unintentional errors.

var (old fashion): was the only method in the past, but its problem is it may cause logical errors because it does not respect Block Scope (Function Scoped), making error tracking difficult in large projects.

Operators 
    
     let a = 10;
     let b = 5;
 
     console.log(a + b); // addition
     console.log(a - b); // subtraction
     console.log(a * b); // multiplication
     console.log(a / b); // division

Addition (+): will add value 10 with 5, result is 15

Subtraction (-): will subtract 5 from 10, result is 5

Multiplication (*): will multiply 10 by 5, result is 50

Division (/): will divide 10 by 5, result is 2

Conditions (If Statement) 
    
     let age = 18;
 
     if (age >= 18) {
     console.log("Entry allowed");
     } else {
     console.log("Entry denied");
     }

Condition (if): we place between the parentheses (age >= 18) a comparison operation. The program asks: "Is the value in age greater than or equal to 18?"

Boolean value: the result of this question is always either true (yes) or false (no)

Execution block { }:

If the condition is true, the code inside the if brackets only is executed

If the condition is false, the program completely ignores the first bracket and immediately moves to what comes after else

    
      let password = "1234";
 
      if (password === "1234") {
      console.log("Login successful");
      } else {
      console.log("Wrong password");
      }

Strict comparison (===): this operator does not only check the "value" (that it is 1234), but also checks the "type" (that it is a String text and not a Number)

Condition structure: since the variable password contains exactly the text "1234", the condition will be met and the welcome statement will be executed

Result: you will see in the Console: Login successful

Loops

for loop

    
     for (let i = 1; i <= 5; i++) {
         console.log(i);
     }

Start (let i = 1): here we create a "counter" and start it from number 1. This part executes only once at the beginning

Condition (i <= 5): before each cycle, the program asks: "Is i still less than or equal to 5?". If the answer is yes, the iteration continues

Update (i++): after the end of each cycle, we increase the value of i by 1 (that is what ++ does)

How does the process go?

Cycle 1: i is 1, prints 1, then i becomes 2

Cycle 2: i is 2, prints 2, then i becomes 3

... and so on until it reaches 5.

End: when i becomes 6, the condition fails (6 <= 5 is false), so the iteration immediately stops

    
       for (let i = 1; i <= 10; i++) {
           console.log("Number: " + i);
       }

Range: the loop will repeat the code 10 times (from 1 to 10)

Plus operator (+): when used with text and a number, it does not perform an arithmetic operation, but "concatenates" the number beside the text to become one sentence

Result: an ordered list will appear in the Console starting with Number: 1 and ending with Number: 10

while loop

Used when you don't know the number of iterations in advance

    
       let i = 0;
 
       while (i < 5) {
           console.log(i);
           i++;
       }

Starting point (let i = 0): you defined the counter outside the loop

Condition (i < 5): before each entry into the loop, the program asks: "Is i less than 5?"

Loop body: the current value of i is printed

Counter update (i++): this line is the most important; without it you will enter an "Infinite Loop" because i will always remain 0, which may cause the browser to hang

do...while loop

Executes at least once even if the condition is false

    
    let i = 0;
 
    do {
       console.log(i);
       i++;
   } while (i < 5);

Execution window (do): the program here executes the code inside the do brackets first without looking at the condition

Update (i++): the counter is incremented inside the loop body

Checking the condition (while): after executing the code, the program goes to check the condition. If true, it goes back and repeats the process

for...of loop

Used with Arrays

    
      let fruits = ["apple", "banana", "orange"];
 
      for (let fruit of fruits) {
          console.log(fruit);
     }

The array (fruits): is a single container that stores a set of values (in this case texts). Note it always starts with [ and ends with ]

for...of loop: this loop is specifically designed to pass through "elements" of arrays. Instead of dealing with numbers and counters (i++) as we did before, it takes each element "automatically"

Variable fruit: in each cycle of the loop, JavaScript places the value of the next element from the array inside this variable

How does this loop work?

First cycle: the variable fruit takes the value "apple" and prints it

Second cycle: the variable fruit moves to the next element "banana" and prints it

Third cycle: the variable fruit takes the value "orange" and prints it

End: when the array is empty, the loop stops automatically

Functions 
    
     function sayHello() {
         console.log("Hello!");
     }
 
     sayHello();

Function declaration: using the word function then a name of your choice sayHello. Here you tell the browser: "Keep this code with you, I will need it later"

Calling the function: writing the function name followed by parentheses sayHello(); is the actual command that tells the browser: "Execute the code inside the box now"

    
     function add(a, b) {
        return a + b;
     }
 
     console.log(add(5, 3));

Parameters (a, b): are just temporary names (inputs) for the raw materials the function will need to work

Keyword return: this is the most important part here; it tells the function: "Stop working here, and take this result with you to the outside". Without return the function result will be undefined

Call add(5, 3): here you passed the actual values (Arguments). a took value 5, and b took value 3

Printing: the console.log statement received the number 8 (which came out of the function) and displayed it

User interaction 
    
     let name = prompt("Write your name:");
 
     console.log("Welcome " + name);

prompt() function: is a built-in browser function that displays a small window containing an input field and an "OK" button. The text you put between the parentheses is the message that will appear to the user

Storing the value: as soon as the user types their name and presses "OK", this text is taken and stored inside the variable name

Concatenation: used the + sign to link the word "Welcome" with the name entered by the user, so the greeting appears customized for them

Arrays 
    
     let fruits = ["apple", "banana", "orange"];
 
     console.log(fruits[0]); // apple

Counting starts from zero (Zero-based Indexing): this is the most important rule! The computer does not start counting from 1 but from 0

First element (apple) its position is 0

Second element (banana) its position is 1

Third element (orange) its position is 2

Square brackets []: used to access the value. Writing fruits[0] means "JavaScript, give me the value at position zero of the fruits array"

    
       let numbers = [1, 2, 3];
 
       numbers.push(4);
 
       console.log(numbers);

The .push() function: adds the element you place between the parentheses directly to the end of the array.

Dynamic modification: arrays in JavaScript are not fixed in size; you can increase or decrease them at any time while the program is running.

Result: when printing numbers at the end, you will see the complete array: [1, 2, 3, 4]

Login system 
    
    let username = prompt("Enter username:");
    let password = prompt("Enter password:");
 
    if (username === "admin" && password === "1234") {
    console.log("Login successful");
    } else {
    console.log("Wrong credentials");
    }

The && (AND) gate: this operator is very strict. For the code inside if to be executed (successful login), both sides must be true at the same time

If name is correct and password wrong → result is false

If name is wrong and password correct → result is false

Only if both are correct → result is true

Verification process: the program compares the text entered by the user in variables username and password with the fixed values you specified (admin and 1234)

URL Defang

This script works as a technical security tool known as "URL Defanging", where it uses regular programming expressions (Regex) to modify the structure of malicious links and prevent accidentally clicking on them. The code replaces sensitive dots in the URL by placing them inside brackets `[.]` and changes the `http` protocol to `hxxp` to transform the link from an active interactive element to mere non-clickable text. From a cybersecurity perspective, the importance of this procedure lies in protecting security analysts and users while exchanging threat intelligence, as it prevents browsers and programs from automatically loading malicious sites. Thus, the script contributes to reducing the risks of software infection when analyzing suspicious links inside security reports, technically transforming the "predatory" link into a safe display-only version.

Brute Force

This script embodies a defensive programming mechanism known as "Brute-Force Detection", where it tracks the number of failed login attempts for each IP address separately and saves them inside a programming object. The code works through an accumulative function that increments the error counter each time a user fails to log in, and when the specified threshold is exceeded (more than 5 attempts), the script immediately fires a security alert warning of a potential intrusion attempt. From a cybersecurity perspective, this script is the first line of defense against brute force attacks that target breaking passwords through trial and error, which allows the system to take subsequent preventive measures like temporarily blocking the suspicious address. The importance of this approach lies in the ability to distinguish between normal human error and the systematic automated behavior followed by intrusion software. Thus, the script provides a vital security layer that protects user accounts from unauthorized access and prevents server resource exhaustion in repeated verification operations.

HTTP Banner Grabbing

This script executes a security technique known as "Banner Grabbing", where it uses the `http` library to send a query request to a specific site with the goal of extracting information from the "HTTP Response Headers". The code specifically focuses on fetching the value of the `server` header which usually reveals the type and version of server software used (like Apache or Nginx). From a cybersecurity perspective, this process is considered the first step in the "Reconnaissance" phase, where it helps analysts identify targets and know whether the server is running an old version containing known vulnerabilities. The importance of this procedure appears in "vulnerability management", where it is security-advised to hide or disguise this information to reduce the data available to attackers about the system's technical infrastructure. Thus, the script transforms a simple connection request into a tool for revealing the identity of technologies running websites, which contributes to assessing the external security level of the organization.

Base64 (Data Exfiltration Simulation)

This script performs "Base64 Encoding", where it uses the `Buffer` object built into Node.js to convert regular texts to a text format based on a system of 64 characters to ensure their safe transfer across different systems. From a cybersecurity perspective, this code represents a means of disguising data and bypassing text filters that may prevent sending special symbols, but it is not considered encryption because it can be easily decoded and does not provide any real privacy for sensitive data. The importance of understanding this distinction appears in preventing falling into a grave security error which is relying on "encoding" instead of "strong encryption" to protect user secrets. Thus, the script works as a tool to convert data formats to facilitate programmatic processing, with constant reminders of the necessity to use real encryption algorithms like AES when dealing with actually sensitive data.

Simple Directory Brute-forcer

This script executes an offensive reconnaissance technique known as "Directory Brute Forcing", where it uses the `axios` library to send sequential HTTP requests to a target site to test the existence of sensitive directories. The code works by attempting to access a list of common paths (like `admin` and `backup`) and checking the server response; if the status code is 200, this means the path is available and accessible. From a cybersecurity perspective, the danger of this procedure lies in revealing control panels or backup files that may not be sufficiently protected, giving the attacker a foothold inside the system. The importance of this check appears in the "vulnerability discovery" phase to assess the extent of web surface exposure to risks, with the security recommendation of the necessity to disable folder viewing and use Web Application Firewalls (WAF) to block such repetitive attempts. Thus, the script transforms the tedious manual search process into a quick tool for testing the robustness of website security configurations.
