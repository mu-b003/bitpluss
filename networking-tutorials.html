What is a network?

A network is a group of devices (computers, phones, printers...) connected to each other to exchange data and resources. Imagine it as a highway on which information travels between devices.

Types of Networks

LAN — Local Area Network

Connects devices in a limited area like home or office. Very fast and secure. Example: home network via router.

WAN — Wide Area Network

Connects networks in wide geographical areas. The Internet is the largest WAN network in the world.

MAN — Metropolitan Area Network

Covers a city or region — larger than LAN and smaller than WAN. Used by telecommunications companies.

WLAN — Wireless Local Area Network

A LAN network but without cables — relies on WiFi and radio waves to transfer data.

Communication media

Ethernet cable (Fastest)

WiFi (Comfortable and fast)

Fiber optics (Fastest thing)

Bluetooth (Short distances)

Satellite (For remote areas)

OSI Model — Network Layers

OSI Model — Network Layers

The OSI model is the reference framework for understanding how networks work — 7 layers working together to transfer data. Imagine sending a message over the Internet like sending a postal package — each layer adds an "envelope" to the data until it arrives, then the envelopes are removed one by one upon receipt. This is called Encapsulation/Decapsulation.

7 Application

User interface with the network — messages and browsers. Protocols: HTTP, FTP, DNS

6 Presentation

Encrypting, compressing, and converting data format. Protocols: SSL/TLS, JPEG

5 Session

Creating, managing, and ending the connection between two devices. Protocols: NetBIOS, RPC

4 Transport

Dividing data and ensuring it arrives in the correct order. Protocols: TCP, UDP

3 Network

Routing and choosing the best path between networks. IP, ICMP, Router

2 Data Link

Transferring data between two devices on the same network, uses MAC. Protocols: Ethernet, WiFi, Switch

1 Physical

Transferring bits (0 and 1) through wires and waves. Protocols: Cables, Hubs, NIC

TCP vs UDP

TCP — Reliable and relatively slow. Guarantees data arrives in order — ideal for websites, email, and file downloads.

UDP — Fast and unreliable. Does not guarantee arrival but much faster — ideal for electronic games and live streaming.

MAC Address

Every network card has a unique MAC address — like a device's fingerprint. 00:1A:2B:3C:4D:5E — 6 pairs of hexadecimal numbers = 48 bits. The first half (3 pairs) = manufacturer. The second half = device number.

IP Addresses and Subnetting

IP Addresses and Subnetting

Every device connected to the Internet needs a unique address — this is the IP address.

Subnetting

Dividing a large network into smaller networks to improve performance and security. The Subnet Mask is used to determine the boundaries.

DHCP — Automatic address distribution

Instead of manually giving each device an IP address, the DHCP server does this automatically when any device connects to the network. This is what your home router does!

Core Protocols

Core Protocols

A protocol is the "language" of communication between devices — a set of agreed-upon rules.

Web and Browsing Protocols
HTTP

HyperText Transfer Protocol — for transferring web pages. Data is unencrypted. Port 80

HTTPS

HTTP with SSL/TLS encryption. Now essential for every website. Port 443

DNS

Resolves domain names (google.com) to IP addresses. Like a phone book for the Internet. Port 53

FTP

File Transfer Protocol — for uploading and downloading files from servers. Port 21

Email Protocols

SMTP

Simple Mail Transfer Protocol — for sending email. Port 25/587

IMAP

For receiving mail while keeping it on the server — works on multiple devices. Port 143/993

POP3

For receiving mail and downloading it locally — older than IMAP. Port 110/995

Network and Management Protocols

ICMP

Used for Ping and Traceroute commands — for testing connection and diagnosing problems. No port

SSH

Secure Shell — for secure encrypted access for remote server management. Port 22

SNMP

For monitoring and managing network devices — routers, switches, servers. Port 161

NTP

Network Time Protocol — for synchronizing time between all network devices. Port 123

How DNS works

When you type www.google.com in your browser:

1. The browser searches the cache first

2. Asks the local DNS server (router)

3. If not found, asks Root DNS Server

4. Then TLD Server (.com)

5. Then Authoritative Server for google.com

6. Returns an IP address like: 142.250.185.78

7. The browser connects to the server directly!

Router

Connects different networks together and chooses the best path to send data. Works at layer 3. Your home router connects your local network to the Internet Service Provider's network. IP Routing, NAT, Firewall, DHCP

Switch

Connects devices within the same local network and intelligently directs data to each device using MAC addresses. Works at layer 2. MAC Table, VLAN, Full Duplex

Hub

Old version of the switch — sends data to all devices at once. Inefficient and slow. Almost no longer used. Works at layer 1. Old, Half Duplex, Broadcast only

Firewall

Protects the network by monitoring and filtering traffic. Allows legitimate traffic and blocks suspicious. Can be an independent device or software. ACL, Stateful, IDS/IPS

Access Point

Adds WiFi coverage to the wired network. Home routers usually contain a built-in access point. WiFi 6, 2.4/5 GHz, WPA3

Ethernet Cable

Network connection cables. Most common types are Cat5e and Cat6. Cat6a speed reaches 10 Gigabits! Cat5e: 1Gbps, Cat6: 1Gbps, Cat6a: 10Gbps

Network Architecture — Topologies

The way devices are connected to each other:

Star Topology

All devices connected to a central switch. Most common — if one device disconnects the others are not affected.

Ring Topology

Each device connected to the next device. Data circulates in a ring. Problem: one device disconnecting affects everyone.

Bus Topology

All devices connected to a single shared cable. Simple but slow and its problems affect everyone.

Mesh Topology

Each device connected to all other devices. Stronger and multi-path but expensive.

Network Security

Protecting your network from threats and electronic attacks.

Most Famous Threats and Attacks

Phishing — Fake messages that look legitimate to steal passwords or your sensitive information.

DDoS Attack — Flooding the server with thousands of requests to disable it. Executed via a Botnet network.

Man in the Middle — The attacker intercepts the communication and eavesdrops on or modifies the data sent.

SQL Injection — Entering malicious SQL commands into website fields to access databases.

ARP Spoofing — Forging MAC addresses to trick devices and direct traffic to the attacker.

Ransomware — Malicious software that encrypts your files and demands a ransom to recover them.

Protection Tools and Techniques

Encryption

Converting data to an unreadable form. AES-256 is the modern encryption standard. Used in HTTPS and VPN.

VPN — Virtual Private Network

Encrypts your connection and hides your real IP address. Makes your Internet connection secure even on public WiFi networks.

IDS/IPS

Intrusion Detection and Prevention System — monitors the network and detects suspicious patterns and acts automatically.

PKI and Digital Certificates

Public Key Infrastructure — guarantees the identity of websites and servers (SSL/TLS certificate).
