Active Directory (AD) Basics

Active Directory (AD) is a directory service developed by Microsoft for managing users, computers, groups, and resources within a Windows domain environment.

It is the most widely used identity and access management solution in enterprise networks.

Why Is Active Directory Important?

Most corporate networks rely on Active Directory for authentication and authorization.

Understanding AD is essential for system administrators, blue teamers, and penetration testers.

What Does Active Directory Manage?

• Users

• Computers

• Groups

• Printers

• Shared Folders

• Security Policies

• Authentication Services

Active Directory Components

Domain

A domain is a logical group of users, computers, and resources managed together.

Example:

company.local
Domain Controller (DC)

A server responsible for authenticating users and enforcing security policies.

The Domain Controller stores the Active Directory database.

Forest

A forest is the top-level container in Active Directory.

It can contain one or more domains.

Tree

A collection of related domains within a forest.

Example:

company.local
sales.company.local
hr.company.local
Organizational Unit (OU)

A container used to organize users, computers, and groups.

Example:

IT
HR
Finance

Active Directory Structure

Forest
 └── Domain
      ├── OU: IT
      ├── OU: HR
      ├── Users
      └── Computers

Users

User accounts represent individuals who can authenticate to the domain.

Example:

john.smith

Groups

Groups simplify permission management.

Instead of assigning permissions to individual users, permissions are assigned to groups.

Examples:

Domain Admins
IT Support
HR Team

Computers

Computers joined to the domain receive centralized management and authentication.

Example:

PC-001
SERVER-01

Authentication in Active Directory

Authentication verifies a user's identity before granting access.

Kerberos

The default authentication protocol used in Active Directory.

It uses tickets instead of sending passwords across the network.

NTLM

An older authentication protocol still found in some environments.

Kerberos is preferred whenever possible.

Kerberos Overview

1- User logs in.

2- Domain Controller verifies credentials.

3- Ticket Granting Ticket (TGT) is issued.

4- User requests access to services.

5- Service tickets are issued.

6- Access is granted.

Group Policy (GPO)

Group Policy Objects are used to centrally manage security settings and configurations.

Examples:

• Password Policies

• Desktop Restrictions

• Software Installation

• Security Configurations

DNS in Active Directory

DNS is critical for Active Directory operations.

Domain members use DNS to locate Domain Controllers and services.

Common Active Directory Ports

53   DNS
88   Kerberos
135  RPC
139  NetBIOS
389  LDAP
445  SMB
636  LDAPS
3268 Global Catalog

LDAP

Lightweight Directory Access Protocol (LDAP) is used to query and manage Active Directory objects.

Example:

ldap://dc.company.local

SMB

Server Message Block (SMB) is used for file sharing and network resource access.

It commonly operates on port 445.

Common Active Directory Accounts

Administrator

Built-in administrative account.

Guest

Limited-access account, usually disabled.

krbtgt

Special account used by Kerberos for ticket generation.

Common Terms to Remember

AD   = Active Directory
DC   = Domain Controller
OU   = Organizational Unit
GPO  = Group Policy Object
LDAP = Lightweight Directory Access Protocol
SMB  = Server Message Block
TGT  = Ticket Granting Ticket

Important Note

Active Directory is one of the most common targets during internal penetration tests.

A strong understanding of AD fundamentals is required before learning Kerberos attacks, BloodHound, Pass-the-Hash, Kerberoasting, and Active Directory Privilege Escalation.
