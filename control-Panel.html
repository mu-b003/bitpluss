Control Panel

It is an old and central location that contains tools for managing system settings.

Click the Windows icon then type Control Panel and press Enter.

'Go to Network & Internet' Network and Internet in Control Panel is the section responsible for network and internet connection settings in Windows.

'Network and Sharing Center' is a section in Windows that helps you view, understand, and manage your device's network connection.

View your active networks

Go to Wi-Fi then Details.

1-Network: Excitel_optimos_2.4

2-Network type: Private network

3-Access type: Internet

4-Connection: Wi-Fi. It is connected to a Wi-Fi network named Excitel_optimos_2.4 and has internet access.

Wi-Fi Status

IPv4 Connectivity: Internet-IPv4 internet connection.

IPv6 Connectivity: No Internet access → IPv6 is not currently used for internet access.

SSID → Wi-Fi network name.

Duration → How long the device is connected to the network.

Speed: 120.0 Mbps → The connection speed between the device and the Access Point not necessarily the actual internet speed.

Signal Quality → Wi-Fi signal strength.

Sent / Received → The amount of data sent and received by the device.

Network Connection Details

IPv4 Address 192.168.1.3 → the device IP address within the network

IPv4 Subnet Mask 255.255.255.0 → Specifies the local network range

Default Gateway 192.168.1.1 → Usually the router

DHCP Server 192.168.1.1 → The device that assigned you the IP address

DNS Server 192.168.1.1 → The device that handles DNS requests

Hardware and Sound

This section relates to hardware, sound, and power. Examples include: Device and Printers, Sound, Power Options, and Device Manager.

Power Options From here you control: Power Plan, Sleep, Turn off display, What happens when you press the Power button, Battery settings

Click on 'Change plan settings'

Turn off the display

On battery: 3 minutes

Plugged in: 3 minutes. This means that if you do not use the device for 3 minutes, the screen will turn off.

Put the computer to sleep

On battery: 5 minutes

Plugged in: 30 minutes. This means that after the device has not been used for this period, Windows enters Sleep Mode.
