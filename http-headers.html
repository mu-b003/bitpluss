HTTP Headers

HTTP Headers are key-value pairs sent between the client and the server.

They provide additional information about the request or response.

Why Are Headers Important?

Headers help servers and browsers understand how data should be processed.

They are also heavily used during web application security testing.

Header Format

Header-Name: Value

Example:

Host: example.com
User-Agent: Mozilla/5.0
Accept: application/json

Common Request Headers

Host

Specifies the target website or virtual host.

Host: example.com
User-Agent

Identifies the browser or client making the request.

User-Agent: Mozilla/5.0
Accept

Specifies the content types accepted by the client.

Accept: application/json
Accept-Language

Specifies the preferred language.

Accept-Language: en-US
Cookie

Sends stored cookies to the server.

Cookie: session=abc123
Authorization

Used for authentication.

Authorization: Bearer TOKEN
Referer

Indicates the previous page visited by the user.

Referer: https://google.com
Origin

Specifies the origin of the request.

Important when testing CORS policies.

Origin: https://example.com
Content-Type

Defines the format of the data being sent.

Content-Type: application/json
Content-Length

Specifies the size of the request body.

Content-Length: 120

Common Response Headers

Server

Identifies the web server software.

Server: Apache/2.4.57
Set-Cookie

Creates a cookie in the user's browser.

Set-Cookie: session=abc123
Content-Type

Defines the type of content returned.

Content-Type: text/html
Content-Length

Specifies the size of the response body.

Content-Length: 2048
Location

Used during redirects.

Location: /login

Security Headers

Strict-Transport-Security (HSTS)

Forces browsers to use HTTPS.

Strict-Transport-Security: max-age=31536000
Content-Security-Policy (CSP)

Helps prevent Cross-Site Scripting (XSS).

Content-Security-Policy: default-src 'self'
X-Frame-Options

Protects against Clickjacking attacks.

X-Frame-Options: DENY
X-Content-Type-Options

Prevents MIME type sniffing.

X-Content-Type-Options: nosniff
Referrer-Policy

Controls how much referrer information is shared.

Referrer-Policy: strict-origin

What Should a Penetration Tester Check?

When intercepting traffic with Burp Suite, pay close attention to:

• Cookies

• Authorization headers

• Host header manipulation

• CORS-related headers

• Missing security headers

• Sensitive information disclosure

GET /profile HTTP/1.1
Host: example.com
User-Agent: Mozilla/5.0
Cookie: session=abc123
