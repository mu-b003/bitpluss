Linux Commands

The `pwd` command prints the current location. And it is /home/kali

The `ls` command is used to display the contents of the current directory.

The `ls -l` command is used to display the contents of the current directory along with detailed information.

The `ls -a` command is used in Linux to display files folders and hidden files any file or folder starting with a dot (.) is considered a hidden file.

The command `cd Desktop` is used to enter the Desktop folder.

The `cd ~` command navigates to the user's home directory.

The `cd` command is also used to navigate to the current user's home directory.

The command `mkdir Folder` creates a folder named "Folder".

Use the `touch File.pdf` command to create a PDF file named "File".

The command `cp File.pdf Desktop/` is used to copy a file from one location to another here we copied the file `File.pdf` to the `Desktop` folder.

The command `mv File.pdf new.pdf` is used to rename a file here we changed the filename from `File.pdf` to `new.pdf`.

The command `rm new.pdf` is used to delete a file.

The `cat bash-test.sh` command is used to display the contents of the file.

`head file.txt` to display the first ten lines of the file.

`tail file.txt` to display the last ten lines of the file.

The command `grep "Hello" file.txt` is used to search for text or a word within the file.

The command `find -name "*.txt"` is used to search for all files ending in `.txt` within the current directory and all subdirectories.

The command `chmod +x file.txt` is used to add execution privileges to a file.

The command `ls -l file.txt` is used to display detailed information about the file the output indicates that adding the execute permission was successful as evidenced by the presence of (-rwxrwxr-x) `x`.

The command `sudo chown root:root file.txt` is used to change the file's owner to root.

Run the command `ls -l file.txt` to verify success the results confirm that the command succeeded and the file is now owned by the root user (root).

`sudo` is used to execute a command with administrator privileges such as `sudo apt update` to update the system.

The `top` command is used to display the processes currently running on the system in real-time.

Results

The `ps` command is used to display the processes currently running in the terminal.

The command `ps aux | grep firefox` is used to search for a process related to the Firefox program and determine whether or not it is running.

The command `echo "Hello Mubarak"` is used to print text to the terminal screen.

The `history` command is used to display the history of commands you have previously used in the terminal.

The `clear` command is used to clear the screen.
