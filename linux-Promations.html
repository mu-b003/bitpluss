Linux Promations

It is a system that determines who can read, modify, or execute files and folders in Linux.

`ls` command used to display the files and folders located within the current directory. It also displays additional details, such as permissions.

Basic Linux Permissions

r--Read--4

w--Write--2

x--Execute--1

No--permission--0

Create a file named `myscript.sh` to test permissions.

Run `ls -l` to check the current permissions the results show that the file currently has read and write permissions only(-rw-ew-r-- 1).

The command `nano myscript.sh` is used to open the file.

The command `#!/bin/bash` tells Linux that this script should be executed using bash.

The command `echo "Hello Mubarak"` prints text to the screen the text we want to print is "Hello Mubarak".

The command `chmod +x myscript.sh` is used to grant the file execute permissions.

After granting the file execution permissions we use the command `ls -l myscript.sh` to verify this.

The result shows that the file has been granted execution permissions(-rwxrwxr-x 1).

It is used to find out the username you are currently using in Linux (kali).

It is used to display information about the current user and their basic privileges in Linux.

uid=1000(kali)

The current user is kali and their UID is 1000.

gid=1000(kali)

Your primary group is kali and its GID is 1000.

27(sudo)

The user 'kali' is a member of the 'sudo' group therefore they can use 'sudo' to execute commands with elevated privileges in accordance with system settings.

The `passwd` command is used to change an account password.

Process Status is an abbreviation used to display the processes that are currently running in Linux.

PID = 31330 → zsh transaction number

TTY = pts/0 → Terminal you are working in

TIME = 00:00:06 → CPU usage time

CMD = zsh → the shell you are using

It is a tool for monitoring processes directly and continuously in Linux.

Tasks: 245 total, 1 running, 244 sleeping, 0 stopped, 0 zombie

245 total → There are 245 processes.

1 running → One process is currently running.

244 sleeping → Processes awaiting/currently inactive.

0 stopped → No stopped process.

0 zombie → No Zombie Processes.

Operations schedule

PID - USER - PR - NI - VIRT - RES - SHR - %CPU - %MEM - TIME+ - COMMAND

31322 - kali - 20 - 0 - 813792 - 73412 - 55452 - 55.1 - 3.7 - 0:06.32 - qterminal

PID → Transaction Number

USER → The user who operates it

%CPU → CPU Consumption

%MEM → RAM consumption

COMMAND → Operation Name

We want to try searching for a running process and then killing it.

The command 'ps aux | grep firefox' It is used to search for a specific process and here we search for any process that contains the word firefox.

We have process number 64538 we will kill this process using the `kill 64538` command.

The process was successfully terminated.
