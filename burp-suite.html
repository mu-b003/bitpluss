Burp Suite

Burp Suite is one of the most popular web application security testing tools.

It acts as an intercepting proxy between the browser and the target web application, allowing security testers to inspect, modify, and analyze HTTP/HTTPS traffic.

Why Use Burp Suite?

Burp Suite helps penetration testers understand how web applications work and identify security vulnerabilities.

It is widely used in web application penetration testing and bug bounty hunting.

How Burp Suite Works

1- Configure the browser to use Burp Suite as a proxy.

2- The browser sends requests through Burp Suite.

3- Burp Suite intercepts the traffic.

4- The tester can inspect or modify requests.

5- Burp Suite forwards the traffic to the server.

6- The server responds through Burp Suite.

Main Components

Proxy

The Proxy is the core feature of Burp Suite.

It intercepts and displays HTTP and HTTPS requests and responses.

Common uses:

• Intercept Requests

• Modify Parameters

• Analyze Responses

• Test Authentication

Intercept

Allows requests to be stopped before reaching the server.

The tester can edit requests and then forward them.

Example Request

GET /profile?id=5 HTTP/1.1
Host: example.com

The tester may modify it to:

GET /profile?id=10 HTTP/1.1
Host: example.com
HTTP History

Displays all requests and responses passing through Burp Suite.

This helps identify application functionality and attack surfaces.

Repeater

Allows sending the same request multiple times with modifications.

Useful for manual testing.

Common uses:

• IDOR Testing

• Authorization Testing

• Parameter Manipulation

• API Testing

Intruder

Automates sending multiple requests with different payloads.

Useful for testing input handling and discovering hidden functionality.

Common uses:

• Parameter Fuzzing

• Content Discovery

• Authentication Testing

• Input Validation Testing

Decoder

Encodes and decodes data.

Supported formats include:

• URL Encoding

• Base64

• Hex

• HTML Encoding

Comparer

Compares requests or responses to identify differences.

Logger

Records traffic and testing activity.

Extensions

Burp Suite supports plugins that extend functionality.

Popular extensions:

• Autorize

• JWT Editor

• Hackvertor

• Active Scan++

Common Testing Activities

Parameter Testing

Modify parameters to identify vulnerabilities.

Example:

?id=5

Change to:

?id=6
Cookie Testing

Analyze and modify session cookies.

Cookie: session=abc123
Header Testing

Inspect and modify HTTP headers.

Authorization: Bearer TOKEN
API Testing

Inspect JSON requests and responses.

{
  "username":"admin"
}

Useful Features for Penetration Testers

Request Editing

Modify requests before sending them.

Response Analysis

Inspect server responses.

Session Handling

Manage authentication sessions.

Scope Control

Limit testing to specific targets.

Burp Suite Workflow

1- Configure browser proxy settings.

2- Intercept traffic.

3- Explore application functionality.

4- Identify interesting requests.

5- Send requests to Repeater.

6- Test parameters and authorization.

7- Analyze responses.

8- Document findings.

Common Keyboard Shortcuts

Ctrl + R → Send to Repeater

Ctrl + I → Send to Intruder

Ctrl + Shift + D → Send to Decoder

Important Note

Burp Suite is not a vulnerability scanner by itself.

Its true power comes from understanding HTTP, web applications, and how to manually test security controls.

Most web vulnerabilities are discovered through careful analysis using Burp Suite's Proxy, Repeater, and Intruder tools.
