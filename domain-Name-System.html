Domain Name System (DNS)

How DNS works

DNS translates website names (such as google.com) into IP addresses that devices understand, so that the browser can access the correct server.

DNS Record Types

A (Address Record) The domain name links to an IPv4 address.

AAAA (Quad A Record) The domain name links to an IPv6 address.

MX (Mail Exchange Record) The domain's email server is identified.

TXT (Text Record) It contains additional textual information (used for verification and security).

CNAME (Canonical Name Record) A subdomain name links to another domain name.

NS (Name Server Record) It identifies the name servers responsible for the domain.

DNS Resolution

It is the series of steps in which the IP address associated with a particular domain name is searched for, starting from the cache and going all the way to the root servers if necessary.

DNS Security

A set of procedures to protect the DNS system from attacks such as record tampering or redirection to malicious sites (e.g., DNSSEC).

Routing & Switching

MAC Address: A unique physical address for each network device, installed on the network card.

ARP (Address Resolution Protocol): A protocol that converts an IP address to a MAC address within a local network.

VLAN (Virtual LAN): A logical network partition that allows devices to be logically separated even if they are connected to the same physical switch.

Routing Basics: The process of choosing the best path to transmit data from one network to another via a router.

Static vs. Dynamic Orientation:

Static Routing: The route is manually determined by the administrator.

Dynamic Routing: Routes are updated automatically using routing protocols (such as OSPF and BGP).
