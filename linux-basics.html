What is Linux?

Linux is an open-source operating system that manages computer hardware and software resources. It allows users to run applications, manage files, and interact with the computer through a command-line interface (CLI) or a graphical user interface (GUI).

Common Linux Distributions:

Ubuntu

Ubuntu is a widely used Linux distribution built on Debian and developed by Canonical. It is known for emphasizing ease of use, regular releases, and broad hardware and software support, making it popular with individuals, businesses, developers, and cloud providers.

Debian

Debian is a free and open-source Linux distribution developed by a global community of volunteers. Known for its emphasis on stability, software freedom, and careful release practices, it has become one of the most influential operating systems in the Linux ecosystem and serves as the foundation for many other distributions.

Fedora

Fedorais a free and open-source Linux distribution developed by the Fedora Project and sponsored primarily by Red Hat. It is widely recognized for delivering the latest stable open-source technologies and for serving as the upstream source of many innovations that later appear in Red Hat Enterprise Linux (RHEL).

Kali Linux

Kali Linux is a specialized Linux distribution designed for cybersecurity, penetration testing, and digital forensics. Maintained by Offensive Security, it is widely used by security professionals, researchers, educators, and students because it ships with hundreds of security-focused tools and receives frequent updates.

CentOS

CentOS is an open-source enterprise Linux distribution and community project focused on providing a stable platform for software development and deployment. Originally known for rebuilding Red Hat Enterprise Linux (RHEL) sources, the project now centers on CentOS Stream, the development platform that sits just ahead of RHEL releases and invites community collaboration.

Terminal

The Terminal is a command-line interface (CLI) that allows users to interact with the operating system by typing commands. It is used to manage files, run programs, configure the system, and perform administrative tasks efficiently.
