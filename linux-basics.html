Linux Basics

Linux is an open-source operating system widely used in servers, cloud environments, cybersecurity, and penetration testing.

Most security tools and platforms run on Linux.

Why Learn Linux?

Linux is essential for:

• Penetration Testing

• System Administration

• Cloud Computing

• DevOps

• Web Hosting

• Digital Forensics

Linux File System

Linux uses a hierarchical directory structure starting from the root directory.

/
├── bin
├── boot
├── dev
├── etc
├── home
├── opt
├── root
├── tmp
├── usr
└── var

Important Directories

/home

Contains user home directories.

/home/mubarak
/root

Home directory of the root user.

/etc

Stores system configuration files.

/var

Contains logs and variable data.

/tmp

Stores temporary files.

/usr

Contains installed programs and libraries.

Navigation Commands

pwd

Displays the current directory.

pwd
ls

Lists files and directories.

ls

Show detailed information:

ls -la
cd

Changes the current directory.

cd /home/user

File Operations

touch

Creates an empty file.

touch notes.txt
cat

Displays file contents.

cat notes.txt
cp

Copies files and directories.

cp file.txt backup.txt
mv

Moves or renames files.

mv file.txt newfile.txt
rm

Deletes files.

rm file.txt

Delete directories recursively:

rm -r folder
mkdir

Creates a directory.

mkdir projects

Viewing Files

head

Displays the first lines of a file.

head file.txt
tail

Displays the last lines of a file.

tail file.txt
less

Views large files page by page.

less file.txt

Searching

find

Searches for files and directories.

find /home -name notes.txt
grep

Searches for text inside files.

grep "admin" users.txt

Permissions

Linux uses permissions to control access to files and directories.

-rwxr-xr--

Permission groups:

Owner | Group | Others
r

Read permission.

w

Write permission.

x

Execute permission.

Changing Permissions

chmod

Modifies file permissions.

chmod 755 script.sh
chown

Changes file ownership.

chown user:user file.txt

Processes

ps

Displays running processes.

ps aux
top

Displays system activity in real time.

top
kill

Terminates a process.

kill 1234

Networking Commands

ip

Displays network interfaces and IP addresses.

ip a
ping

Tests network connectivity.

ping google.com
netstat

Displays network connections.

netstat -tunlp
ss

Modern replacement for netstat.

ss -tunlp

Package Management

APT (Debian / Ubuntu)

Update package lists:

sudo apt update

Install a package:

sudo apt install nmap

Useful Shortcuts

Ctrl + C   → Stop current process
Ctrl + Z   → Suspend process
Ctrl + L   → Clear screen
Tab        → Auto-complete
↑          → Previous command

What Should a Penetration Tester Know?
