Linux folders and files

The `mkdir Mubarak` command is used to create a folder named Mubarak.

The command `mkdir folder1 folder2 folder3` is used to create multiple folders at once.

The `touch file.txt` command is used to create a file named `file.txt`.

The command `touch file2.txt file3.txt` is used to create multiple files at once.

The command `cp file.txt backup.txt` is used to create a copy of the original file but it is saved under the new name.

The command `cp -r folder1 backup-folder` is used to create a copy of the folder but it is saved under the new name.

The command `mv backup.txt Desktop/` is used to move a file from one location to another for example here it moves the file `backup.txt` from the current directory to the `Desktop/` directory.

The command `mv file2.txt new.txt` is used to rename the file from `file2.txt` to `new.txt`.

The command `rm new.txt` is used to permanently delete the file from the system.

The command `rmdir folder1` is used to permanently delete the folder from the system.

The command `rm -r folder3` is used to permanently delete the directory and its contents from the system.

The command `nano file.txt` is used to open the file.

Running the `nano` command opens the file you can type anything inside to test it then press Ctrl+O to save, hit Enter, and finally press Ctrl+X to exit.

The `cat file.txt` command is used to display the contents of the file.

The `head file.txt` command is used to display the first ten lines of the file.

The command `tail file.txt` is used to display the last ten lines of the file.

It is used to display the content of a text file page by page this is useful when the file is long and you do not want to display it all at once.
