Nmap (Network Mapper)

Nmap (Network Mapper) is one of the most popular network scanning tools used for host discovery, port scanning, service detection, and security assessment.

It is widely used by network administrators, security professionals, and penetration testers.

Why Use Nmap?

Nmap helps identify systems, open ports, running services, and operating systems on a network.

It is often the first tool used during reconnaissance and enumeration.

Common Uses

• Host Discovery

• Port Scanning

• Service Enumeration

• Operating System Detection

• Vulnerability Assessment

• Network Mapping

Basic Syntax

nmap [options] target

Example:

nmap 192.168.1.10

Host Discovery

Identify live hosts on a network.

nmap -sn 192.168.1.0/24

The -sn option performs host discovery without port scanning.

Port Scanning

Default Scan
nmap 192.168.1.10

Scans the most common ports.

Scan Specific Ports
nmap -p 80,443 192.168.1.10
Scan All Ports
nmap -p- 192.168.1.10

Scans all 65535 TCP ports.

Common Scan Types

TCP Connect Scan
nmap -sT 192.168.1.10

Completes the full TCP handshake.

SYN Scan
nmap -sS 192.168.1.10

Also known as a Half-Open Scan.

One of the most commonly used scan types.

UDP Scan
nmap -sU 192.168.1.10

Scans UDP services.

Service Version Detection

Identify running services and versions.

nmap -sV 192.168.1.10

Example output:

22/tcp open  ssh   OpenSSH 9.2
80/tcp open  http  Apache 2.4.58

Operating System Detection

Attempt to identify the target operating system.

nmap -O 192.168.1.10

Aggressive Scan

Combines several features:

• OS Detection

• Version Detection

• Script Scanning

• Traceroute

nmap -A 192.168.1.10

Nmap Scripting Engine (NSE)

NSE allows Nmap to perform advanced enumeration and security checks.

List available scripts:

ls /usr/share/nmap/scripts
Run Default Scripts
nmap -sC 192.168.1.10
Run a Specific Script
nmap --script smb-os-discovery 192.168.1.10

Common NSE Categories

• auth

• discovery

• default

• safe

• version

• vuln

Timing Options

Nmap provides timing templates.

-T0 Paranoid
-T1 Sneaky
-T2 Polite
-T3 Normal
-T4 Aggressive
-T5 Insane

Example:

nmap -T4 192.168.1.10

Output Formats

Normal Output
nmap -oN scan.txt target
XML Output
nmap -oX scan.xml target
All Formats
nmap -oA scan target

Common Port States

open
closed
filtered
unfiltered
open|filtered
closed|filtered
Open

A service is actively listening.

Closed

The port is reachable but no service is listening.

Filtered

A firewall or filter is blocking the scan.

Useful Nmap Commands

Quick Scan
nmap target
Full TCP Scan
nmap -p- target
Service Detection
nmap -sV target
Default Scripts
nmap -sC target
Common Enumeration Scan
nmap -sC -sV target
Full Enumeration Scan
nmap -p- -sC -sV target

Nmap Workflow

1- Discover live hosts.

2- Identify open ports.

3- Enumerate services.

4- Detect service versions.

5- Run NSE scripts.

6- Analyze findings.

7- Identify attack surfaces.

What Should a Penetration Tester Check?

• Open ports

• Running services

• Service versions

• Misconfigurations

• Default credentials

• SMB shares

• Web services

• Potential vulnerabilities

Important Note

Nmap is primarily an enumeration tool.

The quality of a penetration test often depends on how well the tester performs enumeration.

Most successful attacks begin with information gathered using Nmap.
