OSI Model

A theoretical model consisting of 7 layers that illustrates how data moves from one device to another across the network, layer by layer.

1 Physical Transmitting raw bits (0 and 1) via cables or air.

2 Data Link Handling physical addresses (MAC) and organizing frames.

3 Network Routing and path determination using IP addresses.

4 Transport Ensuring data is received correctly and completely (TCP/UDP).

5 Session Managing sessions and opening/closing the connection between the two parties.

6 Presentation Data formatting, encryption, and compression.

7 Application The layer that the user interacts with directly (such as the browser, email).
