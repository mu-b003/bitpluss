Variables

A variable is a place in memory where we store a value and can use it later.

    
      name = "Mubarak"     # Text (String)
      age = 20             # Integer
      height = 1.75        # Decimal (Float)
      is_student = True    # Boolean
 
      # Print values
      print("Name:", name)
      print("Age:", age)
      print("Height:", height)
      print("Student:", is_student)

(String) Text: placed between quotation marks " "

(Integer) Whole number: numbers without a decimal point, like 20

(Float) Decimal number: numbers with a decimal point like 1.75

(Boolean) Logical value: can only be True or False

Comparison Operators
    
      a = 10
      b = 5
 
      print(a == b)  # False (are they equal?)
      print(a != b)  # True (are they different?)
      print(a > b)   # True
      print(a < b)   # False

      print(a <= b)  # False

Comparison operations in Python between variables a and b

== checks if the values are equal, and != checks if they are different

> and < are used to find the larger and smaller

>= and <= mean greater than or equal to and less than or equal to

All results are True or False and are displayed using print()

Logical Operators
    
     x = True
     y = False
 
     print(x and y)  # False
     print(x or y)   # True
     print(not x)    # False

Logical operations in Python using True and False values

and returns True only if both values are True, here the result is False

or returns True if at least one is True, here the result is True

not reverses the value, so True becomes False

These operations are widely used in if conditions and decision making in programs

Conditional Statements (If / Else / Elif)

if only

Executes only if the condition is true

    
     num = 10
 
     if num > 5:
        print("Number is greater than 5")

This code demonstrates using the if statement in Python

The value 10 is stored in the variable num

The condition num > 5 checks if the number is greater than 5

If the condition is True, the command inside if is executed

In this case "Number is greater than 5" will be printed

if + else

Either this or that

    
      num = 3
 
      if num > 5:
          print("Big number")
      else:
          print("Small number")

This code demonstrates using if and else in Python

The value 3 is stored in the variable num

The condition num > 5 is checked

If the condition is true "Big number" is printed, and if false else is executed

Since 3 is less than 5, "Small number" will be printed

if + elif + else

elif is used for multiple conditions

    
    num = 10
 
    if num > 10:
        print("Greater than 10")
    elif num == 10:
        print("Equal to 10")
    else:
        print("Less than 10")

This code demonstrates using if, elif, and else in Python

First checks if num > 10, and if not met moves to the next condition

elif is used to check another condition like num == 10

If no condition is met, else is executed

Since the value is 10, "Equal to 10" will be printed

    
      age = int(input("Enter your age: "))
 
      if age < 13:
          print("Child")
      elif age < 18:
          print("Teen")
      else:
          print("Adult")

This code asks the user to enter their age and converts it to a number using int()

if is used to check if age is less than 13 (Child)

elif checks if age is less than 18 (Teen)

If neither condition is met, else is executed (Adult)

The code classifies the person by age as child, teen, or adult

Loops (For / While)

Loops are used to repeat code execution more than once without rewriting it

for loop

range(5) starts from 0 to 4, i is a variable that changes each time

    
    for i in range(5):
        print(i)

This code demonstrates using a for loop in Python

range(5) creates numbers from 0 to 4 (does not include 5)

Variable i takes a new value in each iteration

Each time print(i) is executed

The result will be printing numbers from 0 to 4

while loop

The loop continues as long as the condition is true, i must be incremented to avoid an infinite loop

    
     i = 0
 
     while i < 5:
         print(i)
         i += 1

This code demonstrates using a while loop in Python

Variable i starts at 0

The loop continues as long as the condition i < 5 is true

Each time i is printed then incremented by 1

The result is printing numbers from 0 to 4

Infinite Loop Error

Here the program will not stop

    
    i = 0
 
    while i < 5:
        print(i)

This code contains a while loop without incrementing the variable

i starts at 0 and the condition i < 5 is always true

Because there is no i += 1, the value of i will not change

Therefore the loop will continue forever — Infinite Loop

The number 0 will be printed repeatedly

Loop Control (Break / Continue / Pass)

We use these commands inside for or while loops to control execution.

break — Stop the loop

Stops the loop immediately even if it hasn't finished

    
     for i in range(10):
         if i == 5:
             break
         print(i)

This code demonstrates using break inside a for loop in Python

The loop range(10) prints numbers from 0 to 9

When the value i reaches 5, break is executed

break stops the loop immediately

So only numbers from 0 to 4 will be printed

continue — Skip

Skips the current iteration and continues with the rest

Number 2 is skipped

    
      for i in range(5):
          if i == 2:
              continue
          print(i)

This code demonstrates using continue inside a for loop in Python

The loop prints numbers from 0 to 4

When the value of i equals 2, continue is executed

continue skips this iteration and does not execute print(i)

So the output will be: 0, 1, 3, 4 (without 2)

pass — Temporary placeholder

Does nothing (empty placeholder for code)

The program runs without errors

    
      for i in range(5):
          if i == 2:
              pass
          print(i)

This code demonstrates using pass inside a for loop in Python

pass means do nothing — used as an empty element

When i == 2, nothing changes and execution continues

Therefore print(i) is executed every time

Result: printing numbers from 0 to 4 without change

continue and break together

    
    for i in range(10):
        if i == 3:
            continue
        if i == 7:
            break
        print(i)

This code demonstrates using continue and break together inside a for loop

The loop starts from 0 to 9

When i == 3, printing is skipped due to continue

When i == 7, the loop stops completely due to break

Result: printing 0, 1, 2, 4, 5, 6

Reverse Shell

The second code represents a programming model of what is known as a Reverse Shell, a technique that allows the attacker to control the victim's device remotely by circumventing firewalls. The core idea here lies in reversing the balance of traditional communication; instead of the attacker trying to connect to the victim's device (which most protection programs usually prevent), the victim's device itself creates the connection and exits towards the attacker's device "voluntarily". Functionally, the script uses the socket library to open a direct connection to the attacker's IP address, then enters an infinite iteration loop where it waits to receive text "commands". As soon as the command arrives, the code uses the subprocess library to execute this command inside the victim's operating system as if it were written locally, then sends the result of the execution (such as file contents or system information) back to the attacker. A Reverse Shell is considered one of the most dangerous means used in breaches because it gives the attacker a complete control interface (Terminal) and makes it difficult to detect the connection since it appears in the network as normal outgoing traffic from the device.
