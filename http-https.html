HTTP

HyperText Transfer Protocol It is the protocol that the browser uses to communicate with the server. It operates on a Request/Response system .

Request structure

Response structure:

The most important HTTP methods

GET— It retrieves data (parameters appear in the URL, dangerous because they are saved in history and logs)

POST— It sends data (in the body, relatively more secure but not encrypted except with HTTPS)

PUT/DELETE— You'll often find them in APIs; if they're not protected, you can modify/delete data that doesn't belong to you.

DELETE

OPTIONS— Reveals the methods allowed by the server (useful for Recon)

Response

HTTPS

It's HTTP + TLS/SSL encryption layer. The idea:

The browser communicates with the server (TLS Handshake).

They exchange certificates and encryption keys.

After that, all data is transmitted in encrypted form (even if someone sniffs it, they cannot read it).
