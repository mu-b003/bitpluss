Common Protocols

HTTP (Hypertext Transfer Protocol) Browse web pages without encryption.

HTTPS (Hypertext Transfer Protocol Secure) The same HTTP but with data encryption (more secure).

DNS (Domain Name System) Converting website names to IP addresses.

DHCP (Dynamic Host Configuration Protocol) Automatically distributing IP addresses to devices.

FTP (File Transfer Protocol) Transferring files between devices over the network.

UDP (User Datagram Protocol) A fast transfer protocol, but without guaranteeing data delivery.

SSH (Secure Shell) Secure access and remote control of devices.

SFTP (SSH File Transfer Protocol) Secure file transfer using SSH encryption.

SMTP (Simple Mail Transfer Protocol) Sending emails.

POP3 (Post Office Protocol Version 3) Receiving and downloading emails to the device.

IMAP (Internet Message Access Protocol) Receiving mail while keeping a copy on the server (synchronization).

SNMP (Simple Network Management Protocol) Monitoring and managing network devices.

NTP (Network Time Protocol) Synchronizing time between devices across the network.

ICMP (Internet Control Message Protocol) It is used to test the connection, such as the Ping command.

ARP (Address Resolution Protocol)Converting an IP address to a MAC address within the local network.

Network Devices

Router It connects different networks and routes data between them (such as connecting a home network to the internet).

Switch It connects devices within the same local network and routes data using a MAC address.

Hub An old device that distributes data to all devices connected to it indiscriminately (less efficient than a switch).

Bridge It connects two parts of the same network or two similar networks.

Access Point It provides Wi-Fi connectivity for wireless devices and connects them to the wired network.

Modem It converts the signal from the internet provider into a signal that devices can use.

Firewall It monitors and controls the incoming and outgoing data traffic to protect the network.

Load Balancer The load (requests) is distributed across several servers to improve performance and avoid outages.

Proxy Server An intermediary between the user and the internet, used for security, anonymity, and performance improvement.
