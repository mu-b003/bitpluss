Task Manager

Task Manager is a tool in Windows used to monitor and manage what is happening inside the device at the moment.

Click the Windows icon then type task manager and press Enter.

This will appear to you it contains

Monitoring program and background processes and CPU/RAM/Disk/Network/GPU usage

Performance, CPU, Memory, Disk, Network, GPU: Monitoring device resources

App history shows how apps use CPU, network, and other resources over time.

Startup programs that run automatically when Windows starts: Manage Startup Programs

Users, currently registered users, their processes and resources, and information about user activity.

Very detailed information about processes, such as PID and process name, is crucial for security investigation.

Windows Services and their status (Running/Stopped): Services Management and Monitoring

Name: The name of the process or program.

Status: Process status, such as Running or Suspended

CPU usage percentage. total usage is 4%.

Memory is the amount of RAM used by the process. Your total usage is 36%.

Disk usage by process.

Network: The network is used by the process.

GPU (Graphics Card) usage.

GPU engine: Which part of the GPU is used by the process, such as GPU 0 - 3D.

Power usage: Estimating the impact of the process on energy consumption.

Let's try ending a process: for example, open Notepad, then open Task Manager. Locate Notepad in the list, right-click on it to open a small menu, and select 'End Task' the Notepad program will close automatically.

Go to the 'Startup' section to find the programs that launch automatically when the system starts up. Right-click on any program, and a menu will appear select 'Disable' to stop that program from launching with the system.

You will find Windows Services, which are programs/processes that run in the background to provide functionality to the system or applications.

Press Windows key + R. Something like this will open. Type servics.msc and press Enter.

It will open a list containing :

Service Name

PID is the transaction number associated with the service.

Service Job Description

Status: Running or Stopped

Group of services to which it belongs
