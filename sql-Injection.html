OWASP Top 10

These are the world's most famous 10 vulnerability categories, organized by the OWASP organization and periodically updated based on real data from thousands of assessments. Each section includes theoretical background + a practical example + exploitation method + protection method.

SQL Injection (SQLi)

This occurs when a web application directly embeds user input into a SQL query without sanitization, allowing you to inject your own SQL code and alter the query's behavior.

Vulnerable code example (PHP):

$query = "SELECT * FROM users WHERE username='$user' AND password='$pass'";

The classic exploit — login bypass:

If you type as the username:

' OR '1'='1

The query becomes:

SELECT * FROM users WHERE username='' OR '1'='1' AND password=''

Since '1'='1' is always true, the query returns all users and you log in without a password.

Types of SQLi:

1. In-band (Classic) — the result appears directly on the page, as in the example above.

HTTP Response

HTTP Response

2. Union-based — you use UNION SELECT to pull data from other tables:

' UNION SELECT username, password FROM admin_users--

3. Blind SQLi (Boolean-based) — the page doesn't return an error or data, but its behavior changes (an element appears/disappears). You ask yes/no questions:

' AND 1=1-- (page works normally) ' AND 1=2-- (page changes or fails)

This way you can "guess" the data character by character.

4. Time-based Blind — if there's no visible difference at all, you use the time delay as an indicator:

' AND IF(1=1, SLEEP(5), 0)--

If the page delays 5 seconds = the condition is true.

The essential tool: sqlmap

sqlmap -u "http://example.com/product?id=1" --dbs sqlmap -u "http://example.com/product?id=1" -D shop --tables sqlmap -u "http://example.com/product?id=1" -D shop -T users --dump

Most popular tool: sqlmap

Protection:

Prepared Statements / Parameterized Queries (the only real solution):

Parameterized Query

$stmt = $pdo->prepare("SELECT * FROM users WHERE username=?"); $stmt->execute([$user]);

In this example, a PDO Prepared Statement is used, where the query is sent first, and then the user's value is sent separately, so it is treated as data only.

Using an ORM (like Eloquent, SQLAlchemy) automatically reduces the risk

ORM (Object-Relational Mapping) is a framework that allows a developer to interact with a database using objects instead of manually writing SQL queries.

In most cases, ORM frameworks automatically generate Parameterized Queries, greatly reducing the risk of SQL Injection when used correctly.

Least Privilege for the database account

The Least Privilege principle means that the database account used by the application should have the fewest possible privileges necessary for it to function. If the application only needs to read data, it should not have permissions to delete, drop, or create tables.
