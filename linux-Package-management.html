Linux Package management

Package management refers to the handling of software packages within an operating system; it is used to install, update, and remove software as well as to manage the dependencies required for programs to function.

The `sudo apt update` command is used to update packages.

It is used to update all installed packages to the latest version available in the repositories.

'ss -tuln' This is the result:

Netid State Recv-Q Send-Q Local Address:Port Peer Address:Port

This means that there are currently no services listening on TCP or UDP ports.This is perfectly normal if the Kali system is new and you haven't started any servers, such as: SSH,Apache,Nginx,FTP,Netcat

What is the function of the `ss -tuln` command?

'-t' Display TCP ports

'-u' Show UDP ports

'-l' Show only listening ports.

'-n' Display port numbers instead of service names.
