What Is MITRE ATT&CK?

What Is MITRE ATT&CK?

MITRE ATT&CK is a knowledge base and framework that documents how attackers operate during cyber attacks.

It organizes known adversary behaviors into tactics and techniques, helping security teams understand, detect, investigate, and respond to suspicious activity.

What Are Tactics?

Tactics describe the goal an attacker is trying to achieve during a stage of an attack.

Examples include Initial Access, Execution, Persistence, Privilege Escalation, Credential Access, Discovery, Lateral Movement, Collection, and Exfiltration.

Thinking about tactics helps analysts understand where a particular activity fits within a larger attack.

What Are Techniques?

Techniques describe how an attacker may achieve a particular objective.

For example, under the Execution tactic, an attacker may use techniques involving command and scripting interpreters. Under Credential Access, different techniques can describe methods used to obtain credentials.

Some techniques also contain sub-techniques that provide more specific descriptions of attacker behavior.

How SOC Analysts Use MITRE ATT&CK

SOC analysts can use ATT&CK to add context to alerts and investigations.

Alert → Evidence → Identify Behavior → Map to ATT&CK → Investigate

For example, an alert showing suspicious PowerShell activity can be investigated by examining the command, parent process, user, host, timestamp, and related events. The observed behavior can then be mapped to the relevant ATT&CK technique when appropriate.

MITRE ATT&CK and Detection

ATT&CK can help security teams identify what types of attacker behavior they should be able to detect.

Instead of focusing only on individual indicators such as IP addresses or file hashes, analysts can also look for behaviors that may remain relevant even when attackers change their infrastructure.

MITRE ATT&CK and Threat Hunting

Threat hunters can use ATT&CK techniques as a starting point for proactive searches.

For example, a hunter may choose a technique related to command execution and search endpoint or process logs for unusual command-line activity.

This approach helps turn a general question such as "Is there suspicious activity in this environment?" into a more focused investigation.

MITRE ATT&CK and Incident Investigation

During an investigation, multiple events may represent different stages of an attack.

Mapping relevant behaviors to ATT&CK can help analysts organize those events and understand how they may be connected. It can also help communicate findings using a common security vocabulary.

Simple Example

Imagine an analyst discovers that a suspicious script was executed on a Windows system.

The analyst can examine the process that launched the script, the user who executed it, the command-line arguments, network connections, and other related events.

If the behavior matches a documented ATT&CK technique, the analyst can use that technique to describe the observed behavior and continue looking for related activity.

ATT&CK Is Not an Attack Tool

MITRE ATT&CK is primarily a knowledge base and framework for understanding adversary behavior. It is not a SIEM, antivirus product, or incident-response platform.

Security teams use it alongside tools such as SIEM, EDR, threat intelligence platforms, and other security technologies.

Key Takeaway

MITRE ATT&CK gives SOC teams a structured way to understand how attackers behave.

For a SOC analyst, learning ATT&CK helps connect security events and alerts to broader attacker tactics and techniques, making investigations and detection work more structured.
