LDAP (Lightweight Directory Access Protocol)

LDAP (Lightweight Directory Access Protocol) is a protocol used to access, query, and manage directory services.

In Active Directory environments, LDAP is commonly used to retrieve information about users, groups, computers, and other domain objects.

Why Is LDAP Important?

LDAP is one of the primary methods used to interact with Active Directory.

Many enumeration, administration, and penetration testing activities rely on LDAP.

What Can LDAP Store?

• Users

• Groups

• Computers

• Organizational Units (OUs)

• Printers

• Shared Resources

• Security Information

LDAP Structure

LDAP organizes information in a hierarchical structure called the Directory Information Tree (DIT).

DC=company,DC=local
│
├── OU=IT
│   ├── CN=John Smith
│   └── CN=Server01
│
├── OU=HR
│   └── CN=Jane Doe
│
└── OU=Finance

LDAP Components

Domain Component (DC)

Represents parts of the domain name.

Example:

DC=company,DC=local
Organizational Unit (OU)

Used to organize directory objects.

Example:

OU=IT
Common Name (CN)

Represents the object's name.

Example:

CN=John Smith

Distinguished Name (DN)

A Distinguished Name uniquely identifies an object in LDAP.

Example:

CN=John Smith,OU=IT,DC=company,DC=local

LDAP Ports

389  LDAP
636  LDAPS (LDAP over SSL/TLS)

LDAP Authentication

LDAP supports authentication before allowing access to directory information.

Common authentication methods:

• Anonymous Bind

• Simple Bind

• Kerberos Authentication

• NTLM Authentication

LDAP Bind

A Bind operation is used to authenticate to the LDAP server.

Example:

ldap://dc.company.local

LDAP Operations

Bind

Authenticate to the LDAP server.

Search

Query directory objects.

Add

Create new directory objects.

Modify

Update existing objects.

Delete

Remove directory objects.

LDAP Search Example

Search for all users:

(objectClass=user)

Search for all computers:

(objectClass=computer)

Search for a specific user:

(sAMAccountName=john)

Common LDAP Attributes

cn
mail
memberOf
sAMAccountName
userPrincipalName
description
pwdLastSet

Example LDAP Entry

CN=John Smith
OU=IT
DC=company
DC=local

mail=john@company.local
sAMAccountName=john

LDAP in Active Directory

Active Directory stores most domain information within LDAP-accessible directories.

Administrators and security tools frequently query LDAP for information gathering.

Common LDAP Enumeration Targets

• Users

• Groups

• Domain Controllers

• Service Accounts

• Organizational Units

• Group Policy Objects (GPOs)

• Domain Trusts

Anonymous LDAP Access

Some LDAP servers allow anonymous queries.

This may expose valuable information to attackers.

Common LDAP Security Issues

Anonymous Bind Enabled

Allows unauthenticated users to query directory information.

Weak Access Controls

Users can access more information than necessary.

Excessive Information Disclosure

Sensitive details exposed through LDAP queries.

Insecure LDAP

Using LDAP instead of LDAPS may expose credentials on the network.

LDAP Enumeration Tools

Common tools include:

• ldapsearch

• BloodHound

• PowerView

• SharpHound

• ldapdomaindump

Example ldapsearch Command

ldapsearch -x
-h 192.168.1.10
-b "DC=company,DC=local"

What Should a Penetration Tester Check?

• Anonymous LDAP access

• User enumeration

• Service accounts

• Domain Admins membership

• Kerberos-related information

• Delegation settings

• Sensitive attributes

• Domain trusts

• GPO information

Useful Commands

ldapsearch

ldapdomaindump

Get-ADUser

Get-ADGroup

Get-ADComputer

Common Terms to Remember

LDAP   = Lightweight Directory Access Protocol

DN     = Distinguished Name

DC     = Domain Component

OU     = Organizational Unit

CN     = Common Name

DIT    = Directory Information Tree

LDAPS  = LDAP over SSL/TLS

Important Note

LDAP is one of the most important enumeration sources in Active Directory.

Many attack paths begin with information gathered through LDAP before moving to Kerberoasting, BloodHound analysis, privilege escalation, and lateral movement.
