Operations on files and folders

Transfer the file

To move the file to a folder for example to the 'Docs' folder right click on the file and select 'Copy'

Open the Docs folder by double-clicking it.

Now that you are inside the Docs folder, right click on any empty space and select Paste.

cutting the file

The file was pasted successfully.

Let's try another method cutting the file and pasting it into another folder.

Right-click the file and select Cut.

Double-click to enter the Backup folder.

right click on any empty space and select Paste.

As you can see the file has been successfully cut and pasted.

As you can see the file has disappeared from Docs and moved to Backup the 'Cut' action removes the file from its original location and transfers it to the destination where we pasted it.

Delete the file

Right-click the file then select Delete.

Exit File Explorer then open the Recycle Bin.

Right-click the file and select 'Restore' to return it to its original location this is useful if you have deleted the file by mistake.

The file has returned to the location from which we deleted it.
