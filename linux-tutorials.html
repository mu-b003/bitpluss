What is Linux

Linux is a Kernel for a free and open source operating system, representing the backbone of most servers, cloud systems, and even smartphones (Android). Originally, Linux is a "kernel" (Kernel) developed by Linus Torvalds in 1991. Combined with the tools of the "GNU" project, we got a complete operating system. The most important characteristic is that it is Open Source, meaning anyone can see the programming code, modify it, and distribute it.

Permissions

Each file has 3 types of permissions:

r = read

w = write

x = execute

ls -l

Divided into:

Owner

Group

Others

Change permissions chmod

Gives all permissions to everyone

chmod 777 file2.txt

Read and write for owner + read only for others

chmod 644 file2.txt

Read permission for others

chmod 644 test.pdf

Give write permission to others

chmod o+w test.pdf

Give execute permission

chmod o+x test.pdf

Remove execute permission

chmod o-x test.pdf
