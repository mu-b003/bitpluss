Cybersecurity Notes

Welcome to BIT+, a practical collection of cybersecurity notes created for students and learners who want to understand security concepts through clear explanations and real-world examples.

The material focuses on the fundamentals that are useful when working with security logs, investigating suspicious activity, understanding network traffic, and building a strong foundation in cybersecurity.

Each topic is written to be easy to read and useful during study or practical investigation. The goal is not to overwhelm you with theory, but to help you understand what a security event means, where it appears, and what an analyst should look for.

What You Can Learn

Learn how common Windows, Linux, and network events appear in logs, how normal activity differs from suspicious behavior, and how to approach an investigation step by step.

Use the notes as a reference while studying, practicing in a lab, or reviewing a topic before working on a security investigation.
