Network Security

Firewalls: They monitor and control data traffic based on specific security rules.

IDS & IPS: Intrusion Detection Systems (IDS) monitor suspicious activities, while Intrusion Prevention Systems (IPS) work to actually stop them.

IPS:

VPN (Virtual Private Network): Creates an encrypted and secure connection over the internet, and is used to protect privacy and secure remote access.

ACL (Access Control List): Lists that specify who is allowed to access certain resources on the network.

Network Segmentation: Dividing the network into separate parts to reduce the impact of any breach and improve security.

Zero Trust: A security model that does not automatically trust any device or user, even if they are within the network, and requires continuous verification of every access process.

Network Monitoring

Wireshark: A popular tool for capturing and analyzing data packets passing through the network in detail.

Ping: A command used to test the connection between two devices and determine the response time.

Traceroute: A tool that shows the path data takes through devices and networks until it reaches its destination.

Traffic Analysis: Studying patterns of data flowing in a network to discover problems or threats.

Packet capture: Recording packets sent and received across the network for later analysis.
